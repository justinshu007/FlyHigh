PROJECT TITLE: FISH BLAST

PURPOSE OF PROJECT: 
Fish Blast is an interactive educational game designed using a cognitive 
science approach for primary school students in Grades 1 to 3 (ages 6–9). 
The game uses visual engagement, immediate feedback, and spaced repetition 
to strengthen foundational skills such as working memory, pattern 
recognition, quick decision-making, and basic problem-solving.

USER INSTRUCTIONS:
1. Launch the game and click the "Start" button on the main menu.
2. Choose the level you want
3. Use keyboards on your PC to answer the questions. Use the mouse to navigating the menu.
4. Earn points and combos for accurate, consecutive answers. Completing 
   a stage unlocks higher levels with faster speeds and new cognitive 
   challenges.
